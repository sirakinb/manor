# Manor design references

These files record the current logo and sprite direction. Use them as references
when maintaining Manor's visual identity.

| File | Purpose |
| --- | --- |
| [reference-logo.png](reference-logo.png) | Logo reference |
| [manor-sprites.png](manor-sprites.png) | Combined bot sprite reference |

The current logo and sprites are the approved baseline. Use the existing
[individual sprites](../apps/web/public/sprites/) when you need a single bot image.
See the [asset guide](../public/README.md) for the logo locations.

Forks are welcome to use their own branding and artwork. The references describe
this project's defaults, not a requirement that every fork look like Manor.
