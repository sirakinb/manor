# Manor brand assets

The current Manor logo and bot sprites are the approved visual baseline for this
project. A redesign or expanded sprite family is not part of the current roadmap.

| Asset | Location | Purpose |
| --- | --- | --- |
| Root logo | [logo.png](logo.png) | Root-level logo asset |
| Application mark | [manor-mark.png](../apps/web/public/manor-mark.png) | Mark used by the repository README |
| Individual bot sprites | [sprites](../apps/web/public/sprites/) | Existing bot sprite set |
| Design references | [reference guide](../references/README.md) | Logo reference and combined sprite sheet |

Forks can keep Manor's logo and sprites or substitute their own identity. When
adapting assets, check the README and the relevant application surfaces so each
uses the intended version. Preserve proportions and avoid stretching the artwork.

Keep existing attribution and bundled notices with reused material. See
[NOTICE](../NOTICE) and [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
