# Desktop icons

Manor ships its own icons from this folder.

- `icon.icns` is the packaged Mac icon (`build.mac.icon` in `package.json`).
- `icon-macos.png` is the matching development export with Dock margins.
- `icon.png` and `icon.ico` are the Linux and Windows assets.

Upstream's layered `Rakazo.icon` source in
[`packages/ui-tokens/assets`](../../../packages/ui-tokens/assets/README.md) is not used by
Manor's build.
