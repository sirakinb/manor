Upstream sync #9 — private spaces

  • Delegation chatter between bots now folds into quiet peer receipts instead of flooding the transcript, and messages take a persistent 👍.

  • Manor's dark sign-in kept its look and learned upstream's keyboard manners on Android.
  • All 10 new strings translated — every locale still at zero missing.
  • Kept through the merge: the CRM, phone surface with Manor branding, activity feed, skin, and the Team Computer fixes.

Upstream sync #8 — agents you can text, and a browser of their own

  • Upstream landed a phone surface: people text a shared number and get an agent back over iMessage, with approval-gated group channels and cross-workspace agent-to-agent connections. It ships off by default behind a provider-neutral messaging adapter, so nothing changes until Manor turns it on.
  • Agents get builtin web_search and web_fetch instead of driving a browser for every lookup.
  • Auto Review flags consequential actions nobody asked for, and a new Approval Rules setting controls it.
  • Mobile: Android chat parity, a rebuilt thread list that stays responsive on long conversations, live notifications, and avatars that animate while a bot works — Manor's sprite avatars sit on top of the new motion.
  • Desktop: the conversation header is draggable again, and external links open in the real browser.
  • Fixes worth having: run failures surface in the composer instead of the turn ending silently, sidebar bot order persists across reloads, scheduled routines stop recursing, and Docker browsers survive a crash without the restore-pages bubble.
  • All 25 new strings translated in de, ko, tr, hi and pt-BR — every locale back to zero missing.
  • Kept through the merge: the CRM, the API docs page, Manor's skin and sprites, channel messaging, the activity feed, and the four Team Computer fixes.

Upstream sync #7 — webhook triggers and quieter failures

  • Routines can now fire from an inbound webhook, not just a schedule: the new routine editor grows an "Add trigger" menu, and each webhook gets its own rotating bearer key.
  • Unexpected RPC errors are logged server-side instead of vanishing behind an opaque 500, so the next bug report comes with a stack trace.
  • Sandbox hardening: the computer image survives restrictive host umasks, E2B screen setup gets a real timeout, a failed reconnect provisions a fresh sandbox instead of wedging, and transport errors surface out of computer replacement.
  • Self-hosting: a pull-based Compose flavour that runs from prebuilt images, plus MCP allowlist reporting.
  • All 31 new routine-editor strings translated in every locale — de, ko, tr, hi, pt-BR stay at zero missing.
  • Kept through the merge: the CRM, the API docs page, Manor's skin, channel messaging, and the Team Computer fixes.

Upstream sync #6 — group organization, avatar styles, and a security pass

  • Pin and reorder bots in the sidebar; the group list picks up sections and faster indexes.
  • Choose your avatar style — Robot sprites or Organic — from Settings. The setting was inert before; now it actually repaints every avatar and keeps each bot's colour.
  • The CRM speaks all six languages. It was the last untranslated surface; plural rules are real plural rules, not English glued onto a placeholder.

  • Fixes: the agent home store no longer loses files under concurrent checkout (it was returning 2 of 200), and a sleeping Team Computer can't take the worker down with it on shutdown.
  • Kept through the merge: the CRM, sprites and skin, channel messaging, Team Computer fixes, and Manor's computer-network pinning on the VPS.
